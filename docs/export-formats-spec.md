# 書き出し形式選択と PDF 書き出し仕様

- 対象: iPadOS Safari（ホーム画面追加 PWA を含む）上の MangaSketcher エディタ
- 本文書の地位: 実装契約。数値・文言・失敗時の挙動に「あとで決める」は置かない
- 既存仕様との関係:
  - `docs/web-implementation-spec.md` §1.2 の非ゴール「書き出し（PNG/PDF/ZIP/共有シート）」を、本機能で上書きする
  - `docs/export-workspace-spec.md` の **ページ合成・ZIP 内部・サニタイズ・共有/ダウンロード 2 段階** は存続する。同文書の「PDF は非ゴール」「ページ選択は非ゴール」「生成中キャンセルボタンは置かない」は **本文書が上書き** する
  - サーバ送信は依然非ゴール
- 曖昧語（適宜・必要に応じて・将来・TBD・相当）は仕様欠陥とする

本文書は 2026-09-01 の設計合意を固定する。用途は **画面で読む・メールやチャットで渡す** である。印刷所入稿（トンボ・CMYK・用紙規格）は対象外である。

---

## 1. 目的と非目標

### 1.1 目的

ワークスペース右上の「書き出し」から、次の 4 形式を選べるようにする。ページ画像の層順は現行 PNG 書き出しと同一（白地 + 原稿用紙テンプレ + 「1」隠し + インク + テキスト）である。

| 形式 ID | パネル上の文言（一字一句） | 成果物 |
| --- | --- | --- |
| `png` | PNG | 1 ページなら PNG 1 ファイル。2 ページ以上なら PNG + `text.txt` の ZIP（`docs/export-workspace-spec.md`） |
| `pdf` | PDF | 対象ページを 1 つの PDF にしたもの |
| `clip` | CLIP | 1 ページなら `.clip` 1 ファイル。2 ページ以上なら `.clip` の ZIP（現行 CLIP 書き出し） |
| `miniJpg` | ミニネーム用JPG | ワークスペース全ページを、画面と同じ見開き配置で 1 枚の JPEG にしたもの |
| `pack` | バックアップZIP | 現行のプロジェクトパック ZIP（`exportProjectPack`） |

保存の主経路は現行どおり `navigator.share` の「"ファイル"に保存」と `<a download>` の両方である。生成完了後に共有シートを自動実行してはならない。処理は端末内で完結する。サーバ API は使わない。

### 1.2 非目標（この合意でやらない。議論再開もしない）

| 非目標 | 固定理由 |
| --- | --- |
| 印刷所入稿（トンボ・塗り足し・CMYK・断裁） | 用途は画面共有 |
| 見開き 2 ページを PDF 1 枚に並べる | 1 原稿 = PDF 1 ページ |
| ベクターインク | 永続インクは PNG ラスターのみ。再構成しない |
| 検索可能なテキストレイヤ（画像の上に PDF テキストを重ねる） | 見た目は合成済みビットマップに焼き込む。ずれを出さない |
| JPEG をページ単位のダウンロード形式として出す | JPEG ファイルはミニネーム用の 1 枚シートだけ。ページ単位の JPEG 連番は出さない |
| ストック・ゴミ箱・ペーストボード・PDF ペインの書き出し | 対象は `workspaceOrder` の部分集合だけ（`pack` を除く） |
| File System Access API | iPadOS Safari 非対応 |
| 自動で共有シートを開く | transient activation 切れを避ける |
| 書き出し専用サーバ | オフライン完結 |
| ページ範囲のサムネイル選択 | 開始・終了は番号入力 |

## 2. ユーザーフロー

書き出しアイコン（`aria-label` は「書き出し」のまま）を押すと、**今のメニューを挟まず**、アイコン近くの小さなパネル（現行 `.ms-exportMenu` と同じアンカー）に形式選択が出る。画面中央モーダルは使わない。

パネル外の `pointerdown` でパネルを閉じる。生成は開始しない。`generating` 中はパネルを閉じ、アイコンは `disabled`。

同時に進行中の書き出しは 1 つまで。PNG / PDF / CLIP / バックアップZIP は同じ 4 状態を共有する。

| 状態 | 書き出しアイコン | パネル | 進捗とキャンセル | 完了アクション | エラー文 |
| --- | --- | --- | --- | --- | --- |
| idle | 有効 | 開閉可 | 非表示 | 非表示 | 非表示 |
| generating | 無効 | 閉じる | 表示 | 非表示 | 非表示 |
| ready | 有効 | 閉じる | 非表示 | 表示 | 非表示 |
| failed | 有効 | 閉じる | 非表示 | 非表示 | 表示 |

`ready` 中にアイコンを再度タップしたら、保持中の Blob / Object URL を破棄してパネルを開く（作り直しは形式を選んでから）。

書き出し開始時、および `ready` 表示中は配置パネルを閉じる。進捗・完了アクションは配置パネルと重ならない。

### 2.1 パネル画面

パネルは次の 2 画面だけを取る。

| 画面 | 内容 |
| --- | --- |
| `formats` | 形式 5 つ。前回この作品で書き出した形式を選択表示する。未設定なら `pdf` |
| `pages` | `png` / `pdf` / `clip` のみ。ページの選び方と確定 |

`pack` と `miniJpg` をタップしたら `pages` には進まない。その場で生成を開始する（確認なし）。

`png` / `pdf` / `clip` をタップしたら `pages` に進む。生成はしない。

### 2.2 `pages` 画面

同一画面に次を置く。確認専用の次画面は置かない。

1. ページの選び方（排他、初期値は **毎回「全ページ」**。ページの選び方は記憶しない）
   - 「全ページ」
   - 「このページ」
   - 「範囲」
2. 「範囲」のときだけ、整数入力「開始」と「終了」
3. 対象枚数の文言 `{n}ページを書き出す`（`n` は半角数字。空白なし）
4. ボタン「書き出す」と「もどる」

「もどる」は `formats` に戻る。記憶している形式は更新しない。

「書き出す」で生成を開始し、そのとき選んでいた形式を作品の前回形式として記憶する（失敗しても更新する。パネルを開いただけ・もどっただけでは更新しない）。

### 2.3 ページ集合の決定

`W = snapshot.workspaceOrder`。ページ番号は `W` の 1 始まりインデックスである（ストックやゴミ箱は数えない）。

| 選び方 | 対象 |
| --- | --- |
| 全ページ | `W` の全件（先頭が 1 ページ目） |
| このページ | `selectedPageId` が指すページ 1 件。`selectedPageId == null` または `W` に含まれないときは「このページ」を `disabled` にし、「書き出す」も `disabled` |
| 範囲 | 開始・終了を整数化し、**小さい方を開始・大きい方を終了**にしてから `1..W.length` にクランプした閉区間 |

範囲入力の規則:

- `inputMode="numeric"`。小数は切り捨て。非数字は無視して空にする
- 空欄は「今のページ」の番号（`selectedPageId` の 1 始まりインデックス）で埋める。今のページが取れないときは `1`
- 「範囲」に切り替えた瞬間の初期値は、開始も終了も今のページ（取れなければ両方 `1`）
- クランプ後に開始 > 終了にはならない（入れ替えを先に行う）

対象枚数が 0（`W.length === 0` の全ページ、またはクランプ後にページが残らない）なら「書き出す」は `disabled`。0 件の PDF / ZIP / `.clip` は作らない。

対象枚数が `MAX_WORKSPACE_EXPORT_PAGES`（200）を超えることは、`W.length` 自体が 200 超の全ページのときにだけ起きる。その場合「書き出す」は押せてよいが、生成開始直後にループせず `failed` にする（現行 ZIP と同じ。文言は「書き出しに失敗しました」）。

`pack` はページ集合を使わない。現行 `exportProjectPack` の対象（ドキュメント全体とラスター）のままである。

### 2.4 生成中のキャンセル

進捗の横に「キャンセル」を置く（CLIP 現行と同じ文言。パネルは出さない）。

| 操作 | 結果 |
| --- | --- |
| 「キャンセル」 | 生成を中止し、途中 Blob を捨てる。状態は `idle`。エラー文は出さない |
| `generating` 中に画面を離れる（一覧へ戻る・アンマウント） | 同上 |
| 共有シートを閉じる / 共有しない（`AbortError`） | エラー文を出さない。状態は `ready` のまま |
| `ready` のまま別操作（描画など） | 成果物は保持。アイコン再タップでパネルから作り直すまで使える |

PNG / PDF / CLIP / バックアップZIP のどれでも、生成中はキャンセルできる。

### 2.5 完了アクションと失敗

`docs/export-workspace-spec.md` §2.3・§2.5・§9 に従う。文言は次のまま。

| 場所 | 文言 |
| --- | --- |
| 進捗 | `{N}/{M} ページ…`（三点リーダ U+2026。例: `3/12 ページ…`） |
| キャンセル | キャンセル |
| 共有 | "ファイル"に保存 |
| ダウンロード | ダウンロード |
| 失敗 | 書き出しに失敗しました |

進捗の `M` は **今回書き出す枚数**、`N` はその列の 1 始まり（範囲 5–7 なら `1/3` → `2/3` → `3/3`）。`pack` はページループしないため、進捗が取れない間は `…` だけを出し、キャンセルは出す。

`png` / `pdf` はページ間を `await` で区切り、進捗 DOM が描画される隙間を空ける。

## 3. 前回形式の記憶

キー: `localStorage` の `mangasketcher:last-export-format`

値: JSON オブジェクト。キーは `projectId`、値は `'png' | 'pdf' | 'clip' | 'pack'` のどれか。それ以外の値・壊れた JSON は無いものとして扱う。

- その `projectId` のエントリが無ければ初期選択は `pdf`
- undo / `EditorDocument` には載せない（履歴を汚さない）
- プロジェクト削除時にエントリを消す必要はない
- プロジェクトパックを **読み込んで** 新しい `projectId` になった作品は未設定なので `pdf`

## 4. ページ画像（PNG / PDF 共通）

合成は `docs/export-workspace-spec.md` §6 と同一である。画素サイズはスナップショットの `rasterWidth` × `rasterHeight`。縮小・余白・レターボックス禁止。

入力スナップショット・インク encode 待ち・コピーの規則は同文書 §2.2 手順 3–5・§6.4 に従う。対象は §2.3 のページ集合に限る（`workspaceOrder` 全件とは限らない）。

`text.txt` は **PNG の 2 ページ以上 ZIP にだけ**入れる。PDF / 1 ページ PNG / CLIP / バックアップZIP には入れない。`text.txt` のページ見出し番号はワークスペース上の番号（範囲 5–7 なら `005` 相当の見出し）とし、同文書 §7 の連結規則を対象ページだけに適用する。

## 5. ファイル名

`stem` と `TS`（`YYYYMMDD-HHmm`）は `docs/export-workspace-spec.md` §5.2・§5.3 と同一。同一分内の再書き出しは同名になり得る。連番は付けない。

`pad(n)` は `String(n).padStart(3, '0')`。1000 以上は桁を増やしたまま（`1000`）。

`a` = 対象の最初のワークスペース番号、`b` = 最後のワークスペース番号。

### 5.1 ページ系（PNG / PDF / CLIP）

| 条件 | PNG | PDF | CLIP |
| --- | --- | --- | --- |
| 1 ページ | `{stem}_{TS}_p{pad(a)}.png` | `{stem}_{TS}_p{pad(a)}.pdf` | `{stem}_{TS}_p{pad(a)}.clip` |
| 2 ページ以上かつ選び方が「範囲」 | `{stem}_{TS}_p{pad(a)}-p{pad(b)}.zip` | `{stem}_{TS}_p{pad(a)}-p{pad(b)}.pdf` | `{stem}_{TS}_p{pad(a)}-p{pad(b)}_clip.zip` |
| 2 ページ以上かつ選び方が「全ページ」 | `{stem}_{TS}.zip` | `{stem}_{TS}.pdf` | `{stem}_{TS}_clip.zip` |

「このページ」は常に 1 ページなので 1 ページ行を使う。

「範囲」が結果的に `W` 全件と同じでも、選び方が「範囲」なら範囲付きの名を使う。

CLIP の複数ページ ZIP に `_clip` を付けるのは、同範囲の PNG ZIP とファイル名が衝突しないためである。CLIP 全ページの `{stem}_{TS}_clip.zip` は現行どおり。

### 5.2 PNG ZIP の内側

`docs/export-workspace-spec.md` §5.1 に従う。内側 PNG の番号はワークスペース番号（範囲 5–7 なら `005.png` … `007.png`）。フォルダ名は外側ファイルの拡張子を除いた名前と同一にする。

例: 外側 `題_20260901-1400_p005-p007.zip` → 内側フォルダ `題_20260901-1400_p005-p007/`。

### 5.3 バックアップZIP

現行どおり `{stem}_mangasketcher_{TS}.zip`。ページ範囲は付けない。

## 6. PDF 成果物

### 6.1 ライブラリと MIME

- 生成ライブラリは `pdf-lib`（ブラウザビルド）。`jsPDF` は使わない
- `File` の MIME は `application/pdf`
- PDF バージョンは pdf-lib の既定（1.7）でよい

### 6.2 ページ幾何

各 PDF ページは対象原稿 1 ページに対応する。順は対象集合の読み順（`W` の順）。見開きにまとめない。

MediaBox はポイント単位で幅 `rasterWidth`、高さ `rasterHeight`（1 px = 1 pt = 1/72 in）。回転は 0。CropBox は MediaBox と同一。

### 6.3 画像

各ページに、§4 の合成キャンバスを JPEG で埋め込む。

- `convertToBlob({ type: 'image/jpeg', quality: 0.8 })`（`HTMLCanvasElement.toBlob` も同じ引数）
- Blob が null / reject / `size === 0` なら書き出し全体を `failed`
- 埋め込み位置は (0, 0)、サイズは MediaBox 全面。隙間も拡大もしない
- カラースペースは RGB。CMYK 変換はしない
- 透明は残さない（合成が不透明白地のため）

### 6.4 右綴じ

Catalog の `ViewerPreferences` に `Direction: R2L` を付ける。`PageLayout` は `SinglePage`（見開き表示にしない）。対応していないビューアでは左から右に見えることがあり、その場合もページ順（配列順）は変えない。

### 6.5 しおりとページ番号

しおり（Outlines）を付ける。各対象ページに 1 項目。

- タイトルはワークスペース番号の十進文字列（ゼロ埋めなし）。範囲 5–7 なら `5` `6` `7`
- 飛び先は当該 PDF ページの Fit（ページ全体がビューアに収まる）
- 開いた状態で書き出す（ルートの `Count` は正、子を閉じない）

同じ番号を PageLabels にも付ける（Style D、範囲の先頭ページの `Start` をそのワークスペース番号にする。連続区間なのでラベルは 1 辞書で足りる）。ビューアのページ表示が 1 始まりに戻ってはならない。

### 6.6 文書情報

| キー | 値 |
| --- | --- |
| Title | `present.name` を trim し、空なら `無題`（ファイル名サニタイズはしない） |
| Creator | `MangaSketcher` |
| Producer | `MangaSketcher` |

暗号化・印刷禁止・コピー禁止は付けない。

### 6.7 失敗

合成失敗・JPEG 失敗・pdf-lib 例外・中止以外のエラーはすべて `failed`。「書き出しに失敗しました」以外は出さない。欠ページを飛ばした PDF は出さない。

## 7. PNG / CLIP のページ部分集合

合成・ZIP 内部・encode 待ちは現行仕様のまま、入力ページ列だけを §2.3 の集合に差し替える。

CLIP の 1 ページは現行 `mode: 'single'`。2 ページ以上は現行 `mode: 'zip'`。ワーカー・キャンセルプロトコルは現行を使う。パネル上の「.clip形式で保存」「このページを.clipで保存」は廃止し、§2 の共通 UI に統合する。

## 8. UI 配置と文言（追加分）

書き出しアイコンの位置・サイズは `docs/export-workspace-spec.md` §3.1・§3.2 のまま。

形式ボタンはパネル内で縦に 4 つ。前回形式は `aria-pressed="true"` と現行の押下スタイル（`.ms-chromeIconPressed` 相当をメニュー項目に適用）で示す。未選択の 3 つは `aria-pressed="false"`。

`pages` の「全ページ / このページ / 範囲」も排他で `aria-pressed` を付ける。

ヒット領域はどれも最小 44×44 CSS px。

パネルの `role` は `dialog`、`aria-label` は `formats` で「書き出し」、`pages` で「書き出すページ」。

## 9. 受け入れ

次をすべて満たしたら完了とする。実装前に本文書と矛盾するコードを置いてはならない。

1. 書き出しアイコンで形式 5 つが出る。旧メニュー項目「書き出し」「プロジェクトファイルを書き出し」「.clip形式で保存」「このページを.clipで保存」は出ない
2. 未書き出しの作品では PDF が選択表示される。別作品の前回形式は混ざらない
3. 「書き出す」まで前回形式は変わらない。「もどる」だけでは変わらない
4. PNG / PDF / CLIP は全ページ・このページ・範囲を同一画面で選べる。バックアップZIP とミニネーム用JPG は選んだらすぐ生成する
5. 範囲の開始 > 終了は入れ替わる。空欄は今のページになる
6. PDF は合成済みページ画像を JPEG 品質 0.8 で埋め、1 原稿 1 ページ、R2L、しおりがワークスペース番号
7. 1 ページ PNG は `.png`、2 ページ以上の全ページ PNG は現行どおり `{stem}_{TS}.zip`
8. 範囲 PNG/PDF のファイル名に `p005-p012` 形式が入る。全ページの複数ページには入らない
9. 生成中は `{N}/{M} ページ…` の横でキャンセルでき、中止後はエラー文なしで `idle`
10. 完了後は「"ファイル"に保存」と「ダウンロード」が現行どおり出る
11. 対象 0 件や 200 超、合成失敗は「書き出しに失敗しました」だけを出す
12. 印刷所用の追加 UI（トンボ・用紙・DPI）は存在しない
